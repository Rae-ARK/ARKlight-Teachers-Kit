# ARKlight-Teachers-Kit

**Noah** is a small teaching assistant, built as a real application on
top of [ARKlight](https://github.com/Rae-ARK/ARKlight). It exists to
help a student understand a concept — explain, show an example, ask a
question, give an exercise, evaluate the attempt, adapt — not to be a
Q&A box. It's an occasional side project, kept deliberately small.

New here? Start with [`docs/`](docs/README.md) — that's the actual
documentation index, written for first-time contributors.
