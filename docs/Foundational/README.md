# Foundational

The core reading for understanding what Noah is, how it teaches, and
how it relates to ARKlight. **Not deletable** — this is the permanent
design record for the project, updated in place rather than removed,
mirroring how ARKlight's own `docs/Foundational/` treats its
permanent design record.

| File | Covers |
| --- | --- |
| [`OVERVIEW.md`](OVERVIEW.md) | What Noah is, its relationship to ARKlight, the current mindset (side project, occasional, stress relief), and where to look when you need ARKlight's own current API/architecture rather than this repo's notes. |
| [`TEACHING-MODEL.md`](TEACHING-MODEL.md) | The core teaching loop, the design philosophy behind it ("teach, don't just answer"), Noah's explicit teaching actions, and the lesson model. |
| [`DATA-MODEL.md`](DATA-MODEL.md) | The shapes Noah reasons about: `Concept`, `StudentState`, `Lesson` — and the AI-model role within that state (structured decisions around a model call, not state living only inside a conversation). |
| [`SCOPE.md`](SCOPE.md) | What v0.1 actually includes, what's explicitly out of scope for now, the first subject and first milestone, and the project's success criteria. |

Onboarding tip: if you're new here, read `OVERVIEW.md` first, then
`TEACHING-MODEL.md`. `DATA-MODEL.md` and `SCOPE.md` are reference —
come back to them once you're implementing something.
